# โปสเตอร์กฐินสามัคคี วัดเขาพนมโดมวนาราม

หน้า HTML ตามภาพตัวอย่าง มีรายชื่อผู้ร่วมทำบุญจากเอกสาร Word ฉบับจัดระเบียบ 126 รายการใน 3 สาย พร้อมดอกบัวหลายชั้นที่ขยับตามเมาส์ แสงสะท้อนกรอบทอง กลีบดอกไม้ลอย และประกายแสงระยิบระยับพุ่งขึ้นจากตำแหน่งเมาส์หรือการแตะ/ลากนิ้ว เปิดหรือปิดเอฟเฟกต์ได้ และรองรับการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์ เอฟเฟกต์ไม่บังการคลิกหรือเลื่อนหน้า และหยุดวาดเมื่อหน้าต่างถูกซ่อนหรือขณะ Export

บนมือถือ/iOS ประกายตามนิ้วใช้ดาว DOM ขนาดเล็กแทนแคนวาสเต็มหน้าจอ เพื่อลดปัญหาการ compositing ที่อาจบังโปสเตอร์ ส่วนคอมพิวเตอร์ยังใช้แคนวาสตามเดิม

เอฟเฟกต์อยู่ใน `effects.js` ไม่มีพานหมุนหรือ WebGL และลดความละเอียดชั้นประกายแสงพร้อมจำกัดจำนวนอนุภาคเพื่อให้เบาลง องค์ประกอบเคลื่อนไหวทั้งหมดถูกตัดออกจากการ Export เพื่อคงโปสเตอร์ A4 ที่อ่านรายชื่อได้ครบ

## เปิดใช้งาน

**ไฟล์พร้อมส่งต่อ:** เปิด `dist/kathin-poster.html` ได้ทันที เป็น HTML ไฟล์เดียวที่รวมฟอนต์ ภาพ รายชื่อ และเครื่องมือ Export ทั้งหมด ไม่ต้องเก็บโฟลเดอร์อื่นไว้ด้วย และใช้งานแบบออฟไลน์ได้

เปิด `index.html` ใน Chrome หรือ Edge ได้โดยตรง โดยเก็บโฟลเดอร์ `assets` และ `vendor` รวมถึง `names.js`, `styles.css`, `app.js` ไว้ด้วยกัน ฟอนต์และไลบรารีทั้งหมดอยู่ในโปรเจค ไม่ต้องต่ออินเทอร์เน็ตเพื่อแสดงผลหรือดาวน์โหลด หรือเปิดด้วยเซิร์ฟเวอร์ในเครื่อง:

```sh
python -m http.server 8765
```

จากนั้นเข้า `http://localhost:8765` เว็บไซต์เป็น static HTML ใช้กับ GitHub Pages ได้ โดยตั้ง Pages ให้เผยแพร่จาก `main` และโฟลเดอร์ `/ (root)`

## Deploy บน Vercel

ไฟล์ `vercel.json` กำหนด Framework เป็น Other (`null`), Build Command เป็น `npm run build` และ Output Directory เป็น `dist` โดย build สร้าง `dist/index.html` สำหรับ URL หลักและ `dist/kathin-poster.html` สำหรับไฟล์พร้อมส่งต่อ หากเคย deploy ไม่สำเร็จเพราะหา `public` ไม่พบ ให้ deploy commit ล่าสุดหรือกด Redeploy หลังอัปเดตโค้ด

## ดาวน์โหลดโปสเตอร์

บนมือถือ โปสเตอร์ปรับขนาดข้อความ ระยะห่าง และภาพด้วย CSS ตามความกว้างหน้าจอ โดยไม่ใช้ transform ย่อทั้งแผ่นหรือ perspective 3D เพื่อหลีกเลี่ยงการตัดภาพของ Safari/iOS เมื่อแตะและเลื่อนหน้า ประกายตามนิ้วยังคงแสดงได้ ส่วน `mobile.css` สร้างจาก `styles.css` ด้วย `scripts/build_mobile_styles.py` ทุกครั้งที่ build และ Export ใช้เค้าโครง A4 แยกจากเค้าโครงมือถือ

กด **ดาวน์โหลดโปสเตอร์** เลือก JPG, PNG หรือ PDF และความละเอียด 1,200 / 2,400 / 3,600 พิกเซล ไฟล์ดาวน์โหลดมีโปสเตอร์ครบทั้งหน้า ไม่มีแถบเครื่องมือหรือเอฟเฟกต์เคลื่อนไหว ไฟล์ JPG และ PNG มีอัตราส่วน A4 แนวตั้ง (กว้าง 1,200 / 2,400 / 3,600 พิกเซล สูง 1,697 / 3,394 / 5,091 พิกเซล) ส่วน PDF เป็นโปสเตอร์ภาพนิ่งหนึ่งหน้าขนาด A4 210 × 297 มม. จัดหน้า Export ให้กระชับและรักษาสัดส่วนภาพ โดยหน้าเว็บยังคงกว้าง 1,200 พิกเซลและยาวตามเนื้อหาได้ ไม่แบ่งรายชื่อออกหลายหน้า ข้อความใน PDF เป็นภาพและไม่สามารถเลือกคัดลอกได้

## ที่มารายชื่อ

ข้อมูลมาจาก `output/รายชื่อกฐินสามัคคี_ฉบับจัดระเบียบ.docx` ที่ผู้ใช้แก้ไขล่าสุดโดยตรง เก็บการสะกดและช่องว่างภายในชื่อ พร้อมหัวข้อสายและตำแหน่ง โดยปรับเฉพาะช่องว่างหลังเลขลำดับให้แสดงบนเว็บสม่ำเสมอ

- สายคุณสท.ไพรัชต์ เข็มกลัด -คุณประภาพร ทองเนื้ออินทร์: 1 / 25 / 34 / 20 รายการ
- สายร.ต.อิทธิพล บัวด้วง – คุณฐิตามร ทองเนื้ออินทร์: 2 / 2 / 5 รายการ
- สายคุณฐิติพร บุญชู (ร้านเสริมสวยคุณใจ): 4 / 3 / 30 รายการ

`name.json` และ `names.js` สร้างข้อมูลชุดเดียวกันจาก Word พร้อมตำแหน่งย่อหน้าสำหรับตรวจสอบทุกชื่อ หลังแก้ Word ให้สร้างข้อมูลและ HTML ใหม่:

```sh
python scripts/extract_names.py
python scripts/bundle_art.py
python scripts/build_standalone.py
```

## ตรวจสอบ

```sh
npm ci
npx playwright install chromium
python -m http.server 8765 --bind 127.0.0.1
# เปิด terminal อีกหน้าต่าง
npm test
```

ตรวจข้อความทุกรายการกับ Word การล้นกรอบ การดาวน์โหลด JPG/PNG/PDF จริง ความละเอียดเต็มหน้า การ Export บนมือถือ และการลดการเคลื่อนไหว ภาพตรวจงานอยู่ใน `test-results` ซึ่งไม่ถูก commit

## ทรัพยากร

ภาพตกแต่งมาจากภาพอ้างอิงของผู้ใช้ ส่วนท้ายดอกบัว `assets/footer-lotus.png` สร้างด้วย ImageGen โดยอ้างอิงภาพเดิมและแยกออกจากข้อความ เพื่อให้ดอกบัวและลายทองครบรูปโดยไม่มีแถบสีปิดทับ ฟอนต์ Noto Sans Thai ใช้ SIL Open Font License (`assets/OFL.txt`) ส่วน html2canvas 1.4.1 และ jsPDF 2.5.2 ใช้ MIT License เก็บใบอนุญาตไว้ใน `vendor` มีการเก็บไลบรารีในเครื่องเพื่อให้ดาวน์โหลดได้โดยไม่พึ่ง CDN

การสร้างรายชื่อใหม่ใช้ Word ฉบับจัดระเบียบเป็นต้นทาง โดยไม่มีการแทนคำสะกดจากเอกสารเก่า
