# ฐานรายชื่อ Google Sheets → Apps Script → เว็บ

**สถานะ:** เปิด API และเชื่อมเว็บแล้ว โดยตั้ง URL ใน `data-config.json`
เว็บอ่านชีทตอนเปิดหน้าและกดรีเฟรช ส่วนไฟล์ออฟไลน์ใช้ snapshot ที่บันทึกไว้

ชีทหลัก: https://docs.google.com/spreadsheets/d/1c2gkItD39KFWOA0w7NifEEjSjJJMiay3kruieDBkB5o/edit

แท็บ `รายชื่อ` (gid 0) ใช้คอลัมน์ A–F:

| คอลัมน์ | ใช้งาน |
| --- | --- |
| สาย | เลือกหัวข้อสายเดิม 3 สายจาก dropdown |
| ตำแหน่ง | เลือกตำแหน่งตามสาย |
| ลำดับ | จำนวนตั้งแต่ 1 ขึ้นไป ใช้เรียงภายในสายและตำแหน่ง |
| ชื่อและครอบครัว | ข้อความชื่อ ไม่ใส่เลขนำหน้า เก็บช่องว่างภายในตามที่พิมพ์ |
| แสดงบนเว็บ | ติ๊กเพื่อแสดง เอาติ๊กออกเพื่อซ่อน |
| หมายเหตุ | ข้อมูลประกอบ ไม่ส่งออกใน API |

รายชื่อที่ซ้ำต่างสาย/ตำแหน่งคงไว้ ไม่มีการรวมรายชื่ออัตโนมัติ
ลำดับเท่ากันเรียงตามแถวของชีท เลขบนโปสเตอร์เริ่ม 1 ใหม่ในแต่ละหมวด
แถวชื่อว่างข้ามได้ ถ้าสาย/ตำแหน่ง/ลำดับผิด API แจ้งเลขแถวและเว็บเก็บชุดข้อมูลล่าสุดไว้
แถวใหม่ควรติ๊กแสดงบนเว็บ หากช่องนี้ว่างจริง API ถือว่าแสดง
ไม่เปลี่ยนชื่อหัวคอลัมน์ หรือลำดับคอลัมน์

สคริปต์อ่าน CSV จากลิงก์ชีทที่แชร์ให้อ่านอยู่แล้ว ใช้สิทธิ์ `script.external_request` เท่านั้น
ไม่ขอสิทธิ์อ่าน/แก้ไขชีทอื่นในบัญชี ไม่มี API เขียนข้อมูล
ชีทต้องยังเปิดสิทธิ์อ่านจากลิงก์ได้ บุคคลภายนอกอ่านชีททั้งแผ่นได้ตามการแชร์เดิม
ควรใส่เฉพาะข้อมูลสำหรับเผยแพร่ รวมถึงคอลัมน์หมายเหตุ

## แก้ไข/เผยแพร่สคริปต์

โปรเจกต์: https://script.google.com/home/projects/1BP0DoKrUbPteYmTyr_WKnDSooQNdBeVNK6ViacgEUVY5LyVP_7ogodmX/edit

1. โค้ดตรงกับ `Code.gs` และ manifest `appsscript.json` ในโฟลเดอร์นี้
2. Deploy → New deployment → Web app → Execute as Me → Who has access: Anyone
3. นำ URL ลงท้าย `/exec` ใส่ `data-config.json` แล้วรัน `npm run build`
4. ถ้าแก้โค้ดสคริปต์ภายหลัง ใช้ Manage deployments → Edit → New version เพื่อคง URL เดิม

แก้รายชื่อในชีทไม่ต้อง deploy สคริปต์หรือเว็บใหม่ กดรีเฟรชรายชื่อบนเว็บหรือเปิดหน้าใหม่
Google อาจใช้เวลาสั้น ๆ ให้ CSV สะท้อนการแก้ไขล่าสุด

## รูปแบบ API

`GET /exec` ส่ง JSON: `{ok:true,data:{title,source,groups,count},fetchedAt}`
ถ้าข้อมูลผิดส่ง `{ok:false,error}` โดยไม่ทิ้งรายการที่ผิดแบบเงียบ ๆ
`GET /exec?callback=kathin_callback` ส่ง JSONP ชื่อ callback ตรวจด้วยรูปแบบ identifier ที่จำกัด
ใช้เฉพาะรายชื่อสำหรับเผยแพร่ [เอกสาร Content Service ของ Google](https://developers.google.com/apps-script/guides/content)

เว็บอ่าน API ตอนเปิดหน้าและกดรีเฟรช ใช้ textContent แสดงชื่อเพื่อไม่ตีความ HTML
เมื่อ API ขัดข้องมีข้อความบอกว่าใช้ข้อมูลสำรอง/คงชุดล่าสุด
`npm run build` ดึง snapshot จาก API ไปที่ `name.json` และ `names.js` สำหรับเปิดออฟไลน์
ถ้าเชื่อมต่อไม่ได้ยัง build ด้วย snapshot เดิม ไม่มีการดึง Word มาทับฐานชีท
`scripts/extract_names.py` เก็บไว้สำหรับการนำเข้าจาก Word ด้วยมือเท่านั้น

ตรวจการดึงข้อมูลจริงด้วย `node scripts/verify_live_api.cjs` หรือเติม URL เว็บเป็นอาร์กิวเมนต์
